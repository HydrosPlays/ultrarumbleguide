# <a style="color: lime !important;">Generic Character Parameters</a><br>
In this sub-guide you'll learn about the character parameters that are shared across all characters (such as dashing speed, jump height, and such, which is different from character-specific parameters like Denki's Lock-On range, that stuff will be covered in a different page)

# Gravity
Gravity is the parameter that determines how susceptible characters are to gravity's effects. Jumping with Gravity set to 0 will keep the character stuck mid-air, while positive values make the player actually move upwards. This parameter is closely related to the Max Fall Speed parameter, as it limits how influential Gravity is allowed to be.<br>
<br>
All characters have this parameter currently set to -1480.

# Max Fall Speed
Max Fall Speed controls how much a character can be influenced by gravity, as gravity adds the speed, and Max Fall Speed puts a speed cap on it. Positive values allow positive gravity to successfully pull people upwards, as positive Gravity will be hindered by negative Max Fall Speed.<br>
<br>
All characters have this parameter currently set to -4000.

# Slide Adjust Speed For Fall
Slide Adjust Speed For Fall controls the speed at which you move mid-air when not influenced by a Forward Jump (as those have their own speed), such as when you fall off a ledge, or hold forward mid-air after a skill has ended. This might be what allows characters like Mirio to glide long distances mid-air with Acceleration. Setting this value really high will make you dash insanely fast when moving mid-air with your own input rather than thanks to a skill or a Forward Jump. Negative values push you backwards when attempting to fall off a ledge or moving forward mid-air after a skill.<br>
<br>
All characters have this parameter currently set to 500.

# Run (Initial Speed)
Run (Initial Speed) controls the immediate speed you get when walking around without sprinting. This value is kinda irrelevant as it quickly gets replaced by "Run (Last Speed)", as Initial Speed acts more like a smooth gradient into the Last Speed parameter. High values make you walk super fast for a split second then return to normal speeds, while negative values make the player walk backwards for a split second before returning to normal speeds. It's likely that Run Speed tunes are meant to affect this parameter and its Last Speed counterpart, but currently they don't.<br>

## Run (Last Speed)
Run (Last Speed) controls the speed you get when walking around without sprinting after the initial speed. This value is what carries "Run Speed", as msot of the time you're walking without sprinting you're using this value. High values make you walk super fast (Initial Speed will make you slower for a split second, but afterwards you'll be very fast), while negative values make the player walk backwards. It's likely that Run Speed tunes are meant to affect this parameter and its Initial Speed counterpart, but currently they don't. Unlike Dash speed parameters, all characters that have an Initial Run Speed will have a Final Run Speed that's 200 units higher, so the table is unchanged.<br>

# Run (Accel Span)
Run (Accel Span) is the parameter that determines how long it takes for Run (Initial Speed) to reach Run (Last Speed), basically the gradient speed between both. All characters have it currently set to 0.4 seconds, which means Last Speed is reached very quickly, making Run (Initial Speed) not a very useful parameter.

# Run (Initial Turn Span)
Run (Initial Turn Span) controls when will the character be allowed to turn around. This is more of a technical parameter to smoothen animations. Setting it to 0 will make the character instantly turn around with no animation, while huge values will make the character not turn around until the time introduced has passed. All characters have this parameter set to 0.3 seconds.

# Run (Turn Rate)
Run (Turn Rate) controls the rate at which a character turns afterwards. It's basically another technical parameter. All characters have this set to 0.3 units.

# Run End (Brake Span)
Run End (Brake Span) is the amount of time it takes for a character to transition from their walking speed to zero (stop) once the player stops moving the character. All characters have this set to 0.3 seconds.

# Dash Begin (Brake Span)
Dash Begin (Brake Span) is the amount of time it takes for a character to transition from their current non-sprinting speed to Dash (Initial Speed). All characters have this parameter set to 0.6 seconds.

# Dash (Initial Speed) 
Dash (Initial Speed) controls the immediate speed you get when sprinting around. This value grows over a few second until it gets replaced by "Dash (Last Speed). High values make you sprint super fast for a few seconds then return to normal speeds, while negative values make the player walk backwards for a few seconds before returning to normal forward speeds. It's likely that Dash Speed tunes are meant to affect this parameter and its Last Speed counterpart, but currently they don't.<br>

It's likely that Dash Speed tunes are meant to affect this parameter and its Initial Speed counterpart, but currently they don't.<br>

# Dash (Accel Span)
Dash (Accel Span) is the parameter that determines how long it takes for Dash (Initial Speed) to reach Dash (Last Speed), basically the gradient speed between both. All characters have it currently set to 4 seconds, which means Last Speed (the maximum speed) is reached after 4 seconds of non-stop sprinting.

# Dash (Initial Turn Span)
Dash (Initial Turn Span) controls when will the character be allowed to turn around while sprinting. This is more of a technical parameter to smoothen animations. Setting it to 0 will make the character instantly turn around with no animation, while huge values will make the character not turn around until the time introduced has passed. All characters have this parameter set to 0.4 seconds.

# Dash (Turn Rate)
Dash (Turn Rate) controls the rate at which a character turns afterwards while sprinting. It's basically another technical parameter. All characters have this set to 0.05 units.

# Dash End (Brake Span)
Dash End (Brake Span) is the amount of time it takes for a character to transition from their sprinting speed to zero (stop) once the player stops moving the character. All characters have this set to 0.25 seconds.

# Air Dash (Initial Speed)
Air Dash (Initial Speed) is a presumably unused stat whose purpose is unknown beyond what can be implied from its name. All characters have this parameter set to zero.

# Air Dash (Last Speed)
Air Dash (Last Speed) is a presumably unused stat whose purpose is unknown beyond what can be implied from its name. All characters have this parameter set to zero.

# Air Dash (Accel Span)
Air Dash (Accel Span) is a presumably unused stat whose purpose is unknown beyond what can be implied from its name. All characters have this parameter set to zero.

# Air Dash (Initial Turn Span)
Air Dash (Initial Turn Span) is a presumably unused stat whose purpose is unknown beyond what can be implied from its name. All characters have this parameter set to zero.

# Air Dash (Turn Rare)
Air Dash (Turn Rate) is a presumably unused stat whose purpose is unknown beyond what can be implied from its name. All characters have this parameter set to zero.

# Air Dash (Limit Time)
Air Dash (Limit Time) is a presumably unused stat whose purpose is unknown beyond what can be implied from its name. All characters have this parameter set to zero.

# Hovering (Time Rate)
Hovering (Time Rate) is likely the parameter that tells the game by which amount to increase a character's hover speed (such as Endeavor's Armored All Might's and Nejire's), though this isn't the parameter for the hovering speed itself, only the modifier for it. The values characters have for this parameter are yet to be documented, but at the very least non-hover characters have it set to 1.

# Jump Begin (Brake Span)
Jump Begin (Brake Span) is the time it takes to start a jump. All characters have this set to 0.15 seconds.

# Jump Vertical (Span)
Jump Vertical (Span) is the time it takes the character to reach their maximum Vertical Jump Height once the jump has begun. All characters have this parameter set to 0.25 seconds, though Izuku Midoriya OFA's Jump Vertical (Span) increases to 0.5 seconds under the influence of Fa Jin.

# Jump Vertical (Height)
Jump Vertical (Height) is the height of the character's vertical jumps (jumps done without a directional input). High values make the character jump very high, while negative values make them... jump downwards...<br>

# Damage

<p align="center">
    <img src="https://raw.githubusercontent.com/HydrosPlays/ultrarumbleguide/refs/heads/main/images/strikebig.png" width="180" />
</p>

Like in all games, damage is force that reduces a character's health by the values set in the code (decimal damage is rounded up, so 22.1 turns into 23 DMG). Damage can be amplified through Strike Ability Cards, some special tunes, some normal tunes, Plus Ultra, or/and by having teammates using Strike characters. You can also benefit from Defense DOWN debuffs to deal more damage to the affected target. Damage can be lower than expected when hitting enemies with Defense buffs, which can come from Assault Ability Cards, some special tunes, some normal tunes and/or having teammates using Assault characters. In the settings, you can configure how you want damage to show up, so if an enemy receives 20 DMG five times in quick succession, you can either configure it so shows as five 20s popping up, or as only 1 number getting bigger.<br>
<br>
There are various types of damage.

## Normal DMG

As the name implies, this is the most basic form of damage, damaging healthtypes in the following order: Stamina -> Guard Points -> Health Points.<br>
<br>

## True DMG

This is damage that bypasses Stamina and Guard Points, making it particularily lethal. True DMG can be inflicted via some abilities, DoT effects and the Poison Mist, which serves as extra incentive to heal HP. Poison Mist and DoT damage does not cause damage numbers to pop up, but True DMG abilities do.

### Characters with True DMG abilities.
Of this list, Ibara Shiozaki and Strike Tomura Shigaraki are the most dangerous, as at max level they can kill you in just 2 uses of their True DMG moves.

# Healing

<p align="center">
    <img src="https://raw.githubusercontent.com/HydrosPlays/ultrarumbleguide/refs/heads/main/images/supportbig.png" width="180" />
</p>

If damage reduces health, healing recovers it. Healing is mostly found in drinks and Support Ability Cards and Special Tunes, as actual healing abilities are extremely rare among the cast. Some abilities can heal HP, others can heal GP, and others heal both. While not the case for every healing ability, they often don't work inside the Poison Mist in an attempt to prevent camping. In most cases, the healing of abilities is set, and cannot be increased in any way, however Ibara Shiozaki's gamma allows her to heal the amount of damage she has dealt, so increased her gamma's damage will increase the healing she receives.

Being revived or getting up from the DOWN state gives you some HP back, but the HP you're given decreases with each time you get DOWNd. Revives can recover GP if the reviver has the Reinforced Revive tune, though this does not work on Dabi's special action.

### Healers
Characters with the ability to heal themselves and/or teammates (healing by reviving doesn't count). Of this list, Mr. Compress has the weakest and most limited healing, Overhaul has the greatest immediate healing, while Nejire has less healing power but is full of healing sources and gets more healing value than Overhaul fast. Honorable mention to Momo Yaoyorozu as she cannot heal allies directly, but can spawn Full Recovery Drinks which she can drink to heal allies.

# Reviving

<p align="center">
    <img src="https://raw.githubusercontent.com/HydrosPlays/ultrarumbleguide/refs/heads/main/images/revivebig.png" width="280" />
</p>

The community uses the term revive for two different concepts. The first is when a character uses an ability on another to get them out of the DOWN state, while the second is when a character is KOd and they are brought back to the match. Currently, no character can do the latter, but some can do the former. Some revive abilities are physical range, while others are long range. Reviving an ally from the DOWN state will get them back with some HP, which decreases on every revive or if the player gets up when the DOWN timer reaches zero. This HP loss per revive makes it hard for a teammate that has been revived many times to be saved from a deep point inside the Poison Mist, as at one point they'll be revived with so little HP that they'll be unable to drink even small drinks in time.

### Revivers

Characters with revive abilities. Dabi is a special case as he cannot revive others, only himself. Honorable mention to Kurogiri, who cannot revive allies directly, but can teleport them away from danger with ease and help them get up.
