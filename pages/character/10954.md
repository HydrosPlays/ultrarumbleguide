## Datamined Characters
### Ch000

The first character on the list is not Izuku Midoriya, but Ch000. Ch000 is seemingly a special character that holds all common actions and animations all characters share, which actual characters pull from for all non-character specific actions. This makes Ch000 sort of a "mother" or "origin" character. Things like the generic drinking animation and other generic aspects of characters are stored in Ch000's folder.<br>
<br>
If you're "lucky", you might actually be able to see Ch000's icon in-game, as sometimes the game bugs and doesn't attribute kills to the right person, so sometimes you might see Ch000's icon and its Undef role in the Kill Log in the top left corner of the screen.

# Datamined Stages

## St05

St01 is USJ.<br>
St02 is UA Island.<br>
St03 is Chaos City.<br>
St04 is Neo Academia.<br>
and St05 is the fifth map for the main gamemode. Pretty much nothing is known about this stage besides the fact that it's being worked on. Looking back at the release of UA Island, Chaos City and Neo Academia, it's likely that St05 could release in Season 21 (likely starting on January 20th 2027), though this is not guaranteed and is just speculation based on new stages released in the seasons that start in January and end in March.

## St102
St101 is Gym Alpha (Area Control's stage), and St102 is highly likely Area Control's 2nd map, this is due to the fact that this map is in the same range (the 100s) as Area Control's map, and also due to the fact the map has 3 variations, just like Gym Alpha's patterns. It is unknown when this stage will release.

# Datamined Gamemodes

## Orb Battle
Orb Battle is an apparently discontinued (or postponed) gamemode that has been in the works since Season 1. In the game's files it was found that there were objects called "Orbs" that look like small pink spheres, and there's also a file that dictates orb coordinates, the same type of file that lists Kota's spawns and natural civilian spawns. A Character Condition called Orb Penalty was also found.<br>

It is unknown what this mode was about, all we know is that it used the normal battle royale stages (unlike Area Control) and spread "Orbs" across the map and applied an "Orb Penalty" under unknown circumstances.<br>
<br>
Writer's Speculation: Perhaps this mode was about collecting orbs, and the player that got the most orbs at the end of the match (likely determined by either a timer or a maximum orb capacity) would win. It's possible that players with high orb counts would get an "Orb Penalty" condition to hinder their progress and make players with a lower score catch up more easily, making comebacks easier.

# Tuning Datamines

## GP Defense+
The Assault counterpart of the normal tuning effect GP Attack Power+. GP Defense+ is currently unused, as no character carries this effect currently. This normal tune decreases the damage received while having GP by the same values as HP Defense+.

## PU/PC Active Duration+
This is not Assault Endeavor's special tune, this is a normal tuning effect that increases Plus Ultra duration by 0.8s (level 3) or 1s (level 4). Currently no character carries this effect, but perhaps in the future we might see this interesting effect.
